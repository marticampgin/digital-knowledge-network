# Repository working agreement

- Commit every coherent, tested development unit instead of accumulating unrelated work.
- Use concise commit messages that describe the delivered outcome.
- Run the relevant tests, type checks, and build before committing implementation changes.
- Keep user data, `.env`, `.dkn/`, model files, and generated build output out of Git.
- Preserve existing user changes and never rewrite published history unless explicitly requested.
- Push completed work at the end of each requested development milestone.
